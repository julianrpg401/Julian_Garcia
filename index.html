Cómo trabajo

  1. 01

    Entender el negocio

    Me siento con el área que tiene el problema, documento cómo se hace hoy y saco a la luz sus reglas antes de escribir una línea de código.

  2. 02

    Especificar

    Spec Driven Development: cada historia tiene criterios de aceptación verificables, lo que queda fuera de alcance y las decisiones registradas.

  3. 03

    Diseñar la arquitectura

    Clean Architecture con un dominio libre de infraestructura y dependencias entre capas que las pruebas verifican, no solo la documentación.

  4. 04

    Construir con IA, verificar siempre

    Uso Claude Code con reglas y skills del proyecto, y respaldo cada cambio con pruebas unitarias, de integración o golden master y un CI estricto.
